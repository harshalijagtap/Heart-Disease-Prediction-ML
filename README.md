# CardioSense — Heart Disease Risk Predictor

A Flask web app that predicts heart disease risk using a K-Nearest Neighbors classifier trained on the UCI Heart Disease dataset.

## Project Structure

```
heart_disease_app/
├── app.py                  # Flask backend
├── train_model.py          # One-time model training script
├── requirements.txt
├── dataset.csv             # ← You provide this (from Kaggle)
├── model.pkl               # Generated by train_model.py
├── scaler.pkl              # Generated by train_model.py
├── feature_columns.pkl     # Generated by train_model.py
└── templates/
    └── index.html          # Frontend UI
```

## Setup

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Add the dataset
Download `dataset.csv` from Kaggle (UCI Heart Disease) and place it in the project root.

### 3. Train the model (run once)
```bash
python train_model.py
```
This saves `model.pkl`, `scaler.pkl`, and `feature_columns.pkl`.

### 4. Run the app
```bash
python app.py
```

Open your browser at **http://localhost:5000**

## Model Performance

| Metric    | Value |
|-----------|-------|
| Algorithm | K-Nearest Neighbors (k=8) |
| Accuracy  | ~87% on test set |
| Dataset   | UCI Heart Disease (303 rows, 13 features) |

## Features Used

| Feature | Description |
|---------|-------------|
| age | Patient age in years |
| sex | 0 = Female, 1 = Male |
| cp | Chest pain type (0–3) |
| trestbps | Resting blood pressure (mm Hg) |
| chol | Serum cholesterol (mg/dl) |
| fbs | Fasting blood sugar > 120 mg/dl |
| restecg | Resting ECG results |
| thalach | Maximum heart rate achieved |
| exang | Exercise-induced angina |
| oldpeak | ST depression (exercise vs. rest) |
| slope | Slope of peak exercise ST segment |
| ca | Number of major vessels (0–4) |
| thal | Thalassemia type |
